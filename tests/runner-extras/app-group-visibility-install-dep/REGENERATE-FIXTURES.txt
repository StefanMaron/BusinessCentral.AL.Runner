How .alpackages/*.app and .deps-bin/*.dll in this folder were produced
=====================================================================

"AGVI Precompiled Install Dep" (table 66360, Install codeunit 66361) loads as a Tier-1
precompiled dependency: a compiled DLL under .deps-bin/<Publisher>_<Name>_<Version>.dll plus a
symbol package under .alpackages/. Only THIS app group declares it, but every app group of the
combined tests/runner-extras run fires its install trigger (the bundle's dependency install is
shared), and that trigger reads AllObj for its own table (#4448).

Its object ids 66360-66369 sit inside this group's own idRanges (66350-66369) so that
RunnerExtrasIdRangeGuardTests reserves them; this group's AL uses 66350-66359 only.

The dep's AL source must NEVER live inside any runner-extras suite folder: the suite compile
sweeps *.al recursively, and the table would then be source-compiled here, which is not the
shape under test. Keep it in a scratch dir:

  app.json   id 4448a1a1-7a1d-4c38-9e25-1f6d8a4c2660, name "AGVI Precompiled Install Dep",
             publisher "AL Runner Fixtures", version 1.0.0.0, platform 27.0.0.0,
             runtime 17.0, idRanges 66360-66369, no dependencies
  table 66360 "AGVI Install Log" { field(1; "No."; Code[20]) } key PK "No."
  codeunit 66361 "AGVI Install" (Subtype = Install), OnInstallAppPerCompany:
      if not AllObj.Get(AllObj."Object Type"::Table, 66360) then
          Error('AGVI install trigger cannot see its own table 66360 in AllObj');
      insert an "AGVI Install Log" row with "No." = 'INSTALLED'
  a throwaway [Test] codeunit 66362 so the bundle emits a DLL (NOT copied back here)

Regenerate, from the repo root (AlRunner built -c Release):

  python3 tests/runner-extras/app-group-visibility-install-dep/build_symbol_app.py.txt \
      tests/runner-extras/app-group-visibility-install-dep/.alpackages/AL_Runner_Fixtures_AGVI_Precompiled_Install_Dep_1.0.0.0.app
  dotnet run --project AlRunner -c Release -- --verbose /tmp/agvi-dep --package-cache ~/.al-runner/platform-apps
  # prints "[cache] WROTE key=<KEY> path=~/.cache/al-runner/al-out/<KEY>.dll"
  cp ~/.cache/al-runner/al-out/<KEY>.dll \
     tests/runner-extras/app-group-visibility-install-dep/.deps-bin/AL_Runner_Fixtures_AGVI_Precompiled_Install_Dep_1.0.0.0.dll

Both binaries match .gitignore patterns; commit them with `git add -f`.
